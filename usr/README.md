# Asistente de Catálogo Comercial

Una aplicación multiplataforma construida con Flutter que ofrece un catálogo de productos interactivo y un asistente comercial (chat) integrado para resolver dudas sobre los artículos.

## Características

- 📱 **Catálogo Responsivo**: Interfaz adaptable a pantallas móviles, tablets y de escritorio.
- 🛍️ **Detalles de Producto**: Vista completa con descripción, precio y categoría de cada artículo.
- 💬 **Asistente Comercial Integrado**: Chat interactivo simulado que responde a consultas sobre productos, precios y recomendaciones.
- 🎨 **Diseño Moderno**: Interfaz limpia utilizando Material Design 3.

## Tecnologías

- Flutter
- Dart
- Material Design 3

## Instalación y Ejecución

1. Clona el repositorio.
2. Instala las dependencias de Flutter:
   ```bash
   flutter pub get
   ```
3. Ejecuta la aplicación:
   ```bash
   flutter run
   ```

## Flujo de Usuario

1. **Pantalla Principal**: El usuario visualiza la cuadrícula de productos disponibles. Puede acceder al chat mediante el botón flotante o la barra de navegación.
2. **Detalles**: Al tocar un producto, se muestran sus características completas junto con una opción rápida para consultar al asistente.
3. **Chat Comercial**: El usuario interactúa con un asesor virtual (simulado) para obtener más información o recomendaciones.
